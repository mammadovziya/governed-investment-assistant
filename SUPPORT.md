# Support

This project is community-supported open-source software. It is an internal
pilot and reference implementation, not a customer-production brokerage
service, a broker support channel, or a source of personalized investment
advice.

## Where to ask

- Use a GitHub issue for a reproducible bug or a scoped feature request.
- Use GitHub Discussions for implementation questions and design conversation
  when Discussions are enabled.
- Read [README.md](README.md) for setup and capabilities.
- Read [docs/studio-runbook.md](docs/studio-runbook.md) for local Mastra Studio
  and observability troubleshooting.
- Read [docs/production-readiness.md](docs/production-readiness.md) before
  evaluating any deployment beyond a local or controlled pilot.
- Follow [CONTRIBUTING.md](CONTRIBUTING.md) when proposing a change.

Before opening an issue, search existing issues, use the latest default branch,
and run the documented verification commands. Include a minimal reproduction,
Node.js and operating-system versions, the relevant command, and sanitized
error output.

## Please do not post

Never post API keys, session tokens, private keys, raw model transcripts,
account identifiers, real portfolios, orders, customer information, internal
documents, or unredacted traces. This repository accepts only public, approved,
or synthetic data.

Suspected vulnerabilities must be reported privately according to
[SECURITY.md](SECURITY.md). Conduct concerns must follow
[CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

## Scope and expectations

Maintainers and contributors help on a best-effort basis. No response time,
uptime, market-data freshness, migration service, deployment review, or
production support is guaranteed. Repository support does not cover third-party
accounts, provider billing, investment decisions, or loss arising from use of
the software.
