## 0.1.0 - 2026-08-11

### Added

- Bilingual Azerbaijani and English investment-assistant reference UI.
- Governed Mastra workflows, one-use tool grants, signed evidence, constrained
  writers, deterministic financial calculations, and blocking delivery gates.
- Synthetic portfolio and offline market providers for a self-contained demo.
- Shared local Mastra Studio observability with token and estimated model-cost
  metrics.
- Apache-2.0 licensing, contribution and security policies, GitHub templates,
  dependency automation, CodeQL, dependency review, history-aware secret
  scanning, SBOM generation, and OCI provenance evidence.
